CodeNova AI is a modern AI-powered coding assistant built using the MERN stack. It helps developers generate code, debug errors, explain complex logic, and improve productivity with intelligent AI suggestions.

Inspired by modern AI developer tools like GitHub Copilot and ChatGPT coding assistants, CodeNova AI provides a clean UI and powerful developer-focused features.

⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/yourusername/codenova-ai.git
2️⃣ Move Into Project
cd codenova-ai
3️⃣ Install Frontend Dependencies
cd client
npm install
4️⃣ Install Backend Dependencies
cd ../server
npm install
🔑 Environment Variables

Create a .env file inside the server folder.

PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key
▶️ Run Project
Start Backend
cd server
npm run dev
Start Frontend
cd client
npm run dev
